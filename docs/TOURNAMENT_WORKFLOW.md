# Tournament clip workflow

Use this checklist with an editor or an automation agent for tournament footage you are authorized to clip and publish.

## Prepare the event

- Collect the authorized replay or recording links, event name, game, round or match labels, team names, verified scores, and posting rules.
- Set the expected destination channel, visibility, and publishing start time. Use a private sample upload to check the destination and formatting before the event.
- Keep local copies or approved replay links for the clips you may need to re-render.

## Agent instructions

> Use the authorized event recording and verified tournament facts supplied by the editor. Find self-contained gaming moments with a clear setup and payoff. Suggest a 9:16 cut for each moment and flag uncertain dialogue, scores, or team names for review. Use the detected bottom facecam layout when it frames the streamer correctly and keep captions low and readable. Generate a distinct factual title, a description of at least 1,500 characters, and relevant gaming hashtags for each candidate. Use recent YouTube search results as keyword context and show the references. Return the clips and draft copy for approval.

## Review and schedule

1. Play each export to check the 9:16 frame, the facecam inset, caption timing, and whether the audio is cleared for upload.
2. Review the AI drafts against the event notes. Confirm that the copy correctly describes the match and that any participant names cleared for publication are spelled correctly.
3. Order the approved clips in the intended release sequence. Use **Post to YouTube** for an immediate single upload or use the batch scheduler to space the selected clips 10 minutes apart.
4. Monitor the local queue. If a post fails, review the reason, fix the connection or metadata as needed, and retry that entry. Use the returned YouTube link to confirm when a clip is uploaded.

See [YouTube setup, research and posting](YOUTUBE_AUTOMATION.md) for channel connection, platform limits, and retry guidance.
